# Ultraslop Constructor

> **A catastrophically overengineered desktop application that does almost nothing — very expensively.**

Ultraslop Constructor is a parody-grade Electron app that exists to stress-test your patience, your hardware, and your operating system’s coping mechanisms. It proudly combines a low-quality AI model with maximal resource abuse, questionable architectural decisions, and a commitment to never optimizing anything.

---

## ✨ Features

* 🧠 **Terrible AI model** trained on ~6 million Reddit comments
* 🐢 **CPU-only AI inference** (even if you have a perfectly good GPU)
* 🎮 **Invisible WebGL renderers** running in the background so your GPU doesn’t feel left out
* 🧵 **~30 Electron processes** spawned for no defensible reason
* 💾 **Gigantic memory footprint** (measured in "why" rather than MB)
* 💥 **Frequent crashes** (sometimes intentional, sometimes not)
* 🗑️ **Aggressive memory dumping** to disk

  * ~3 GB written every ~5 seconds
  * No cleanup
  * No compression
  * No explanation

---

## 🧠 The AI Model

* Trained on **6,000,000 Reddit comments**
* Output quality ranges from:

  * confidently incorrect
  * vaguely unhinged
  * completely unrelated
* Inference is:

  * blocking
  * slow
  * repeated far more often than necessary

The model is treated as a black box and is reloaded more frequently than it should be. Any attempt to make it smarter, faster, or more coherent is considered a regression.

## 🧨 Performance Characteristics

| Resource | Expected Behavior                                    |
| -------- | ---------------------------------------------------- |
| CPU      | High usage during inference and sometimes while idle |
| RAM      | Rapid growth with no upper bound                     |
| Disk     | Constant writes (~3 GB / 5 seconds)                  |
| GPU      | Busy rendering things you will never see             |
| UI       | Freezes, stutters, or vanishes entirely              |

Task Manager should look **alarming** within seconds.

## 💻 Tech Stack (Poorly Used)

* **Electron** (mandatory bloat)
* **Node.js + Chromium**
* **WebGL** (background-only, invisible)
* **Local AI runtime** (CPU-only, no acceleration)

Best practices were acknowledged and then ignored.
